# Недельный виджет — этап61,1.10.26/code49, Room16

Отдельный виджет с семью строками понедельник–воскресенье. Нажатие даты открывает тот же QuickNoteActivity/экран дня, что месячный виджет: быстрый ввод, автосохранение, время и галочки. «+» открывает быстрый ввод выбранного дня; выбор сохраняется при закрытии окна. Недели листаются независимо по ID, заголовок возвращает текущую неделю. Даты между месяцами/годами и високосный февраль, RU/EN, стиль выполнения/цвета/прозрачность. Минимум272×400dp: семь строк и пять элементов шапки высотой48dp, без узких семи колонок. Это расчёт/проверка layout в облаке, не запуск лаунчера A01.

## Аудит и оптимизация

Общий скалярный источник для недельного и месячного превью: точные агрегатные счётчики по датам и максимум3 коротких заголовка на день. LIMIT3 сначала выбирает ID, только затем читает256 Unicode-кодпоинтов заголовка/16 цвета. Содержимое заметки, оформление, таблицы, вложения/декодеры не загружаются. Зафиксирован порядок активных задач/выполненных/заметок с устойчивым id при равных датах. В транзакции до7 count-строк+21 заголовка на неделю или42+126 на календарную сетку; память результата ограничена и при большом числе записей. «+N» считает все публичные записи, не только загруженные. Room16/протокол2, без новой схемы/зависимостей/разрешений.

Один наблюдатель Room notes/notebooks только при установленных недельных виджетах, IO snapshots с переиспользованием одинаковых недель для нескольких виджетов. distinct settings/кеш RemoteViews, trailing250ms для текста сохраняет последнюю правку; изменение видимости/защиты/выбранной недели/языка/явное действие немедленно. Последний виджет удалён — scope/observer отменяются. Общий для поколений owner Mutex сериализует запись кадра и аварийное очищение; проверка отмены внутри блокировки не даёт старому owner перезаписать новое состояние при повторном подключении. Такая же защита добавлена компактному виджету. updatePeriod0, нет часов, периодического alarm/worker/service. Системные уведомления даты/времени/часового пояса, возврат в приложение и взаимодействия пересчитывают относительную неделю; точность доставки системных событий в лаунчере телефона не измерялась. Существующая периодика месячного виджета не изменялась.

Защищённые заметки/блокноты исключаются даже при открытой сессии, deleted/purged скрыты в превью и общем списке дня. PendingIntent явные и immutable, уникальны по виджету/слоту; при листании extras заменяются без накопления новых токенов на каждую дату. Ошибка очищает строки/старые действия и показывает сообщение. Команды проверяют установленные ID, offset ограничен±520 недель, повреждённый выбор дня нормализуется; удаление чистит prefs.

При аудите общего экрана дня исправлены два случая: устаревшее очищение быстрого черновика проверяет защиту/удаление до softDelete; галочка сверяет syncId показанной записи и отвергает purged/заменённый ID. Прежние разрешённые правки/напоминания/автосохранение/анимации главной сохраняются.

Локально444 теста,0 failures/errors/skipped; lint0 ошибок/15 предупреждений/2 информации, assembleDebug успешно за4m 15s. CI/APK проверяются после публикации. Новые проверки охватывают bounded SQL/точный overflow/Unicode/защиту/неизменность больших тел, границы недель/offset, настоящие apply/reapply RemoteViews/старые действия/стили/EN/размеры/intent общего дня, Room→последняя правка→виджет/защита родителя/стоп/повторное подключение, два независимых виджета/выбор/+ и системное событие времени.
