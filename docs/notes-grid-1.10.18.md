# Этап55 — список/сетка, 1.10.18 / code41, Room14

Переключатель рядом с поиском и настройка «Вид заметок»: список/две колонки переменной высоты. Список остаётся исходным вариантом по умолчанию. На ширине меньше280dp сетка использует одну колонку для доступных кнопок. Выбор сохраняется в настройках.

Общий LazyVerticalStaggeredGrid с1/2 колонками, стабильными ключами и сохраняемым состоянием удерживает текущую заметку при смене вида/ширины и пересоздании. На смене вида сбрасывается только пиксельное смещение текущего элемента; номер якоря хранится по событию перехода между элементами, без таймера/записи в prefs на каждом кадре. Нижний отступ оставляет доступ к последним карточкам под плавающими кнопками.

Фото показываются и в списке, и в сетке: первое изображение заметки, ContentScale.Fit без изменения оригинала. Рамка вычисляется одним layout-проходом с пределом120/180dp; декодирование512px через общий загрузчик53 (не более2 одновременно, STARTED, отмена/ошибка/EXIF). Прямого чтения файлов на UI и полного декодирования оригиналов нет; заглушки статические.

Метаданные всех первых фото получаются одним запросом с группировкой, без N+1 запросов карточек/лимита999 аргументов. Фото-каталог наблюдает только attachments, что подтверждено сгенерированным Room DAO; автосохранение текста не перечитывает каталог. В нём могут оставаться метаданные скрытых/удалённых заметок, но видимость определяет прежний запрос NotesViewModel. Закрытые задачи отображаются отдельными полными строками без заголовка/текста/фото; их файловый загрузчик не вызывается. Каталог отключается сразу при отсутствии UI-подписчика. Дополнительный фильтр текущей сессии немедленно скрывает кешированную заметку при закрытии задачи/блокнота, не дожидаясь debounce SQL-запроса; проверяются оба уровня доступа.

Для видимых карточек предпросмотр ограничен2000 UTF16 текста/256 заголовка, без разрыва surrogate-пары. Тот же безопасный префикс применён к автоматически создаваемому заголовку быстрой задачи (60 UTF16); исходный текст с emoji остаётся целиком. Оформление и текст документа не меняются. Сетка имеет компактные отдельные48dp-действия выполнения/таймера/меню, приоритеты/избранное/таблицы, прежние цвета, статический значок обратного отсчёта; новых опросов или теней в карточках сетки нет.

Общий аудит напоминаний исправил canNotify: теперь учитывается канал reminders с IMPORTANCE_NONE, а не только разрешение/app-wide переключатель. Быстрая задача сохраняет текст и сообщает об отключённых уведомлениях; не объявляет такое напоминание установленным.
