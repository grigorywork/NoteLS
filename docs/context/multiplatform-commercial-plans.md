# Мультиплатформа и коммерция
Цели: порты на iPhone/Windows/Linux, возможная продажа. Путь: Kotlin Multiplatform + Compose Multiplatform, сначала стабильный Android.
Адаптеры при порте: SpeechRecognizer, BiometricPrompt, виджеты (WidgetKit), быстрая заметка, уведомления, Room (KMP-версия есть).
Правило: изолировать платформенный код за интерфейсами. Лицензии Apache 2.0/OFL — коммерция ОК. До релиза: экран "лицензии открытого ПО".
Издержки: Apple Developer $99/год + Mac; Windows — сертификат подписи; Linux — свой сайт.
