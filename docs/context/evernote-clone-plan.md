# NoteLS: план и статус (краткая копия из памяти)
Продукт: заметки под Android, MD3 + динамическая тема, клон Evernote → свой путь. Этапы 0–39 пройдены, v1.10.0.
Синхронизация: TCP+AES-256/GCM, QR notessync://connect TTL 5 мин, ручной ввод IP+кода фолбэк.
Сборки подписаны постоянным ключом проекта (с v1.8.1). Основной проект: приватный GitHub-репозиторий grigorywork/NoteLS, ветка main; коммиты 1.9.0/1.10.0 сохранены.
Рецепт сборки песочницы и все этапы: см. agent.md и ПЕРЕДАЧА-ПРОЕКТА.md.
