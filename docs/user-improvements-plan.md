# NoteLS — единый план этапов 42–68

Обновлён 2026-11-11 по последнему полному списку пользователя. Основной проект — приватный grigorywork/NoteLS, main. Этот план **заменяет прежнюю очередь после этапа 43**: будущие номера перенумерованы, функции объединены без дублей. Старые записи agent.md остаются историей.

## Порядок работы

- Один запуск — один этап, затем аудит, исправление ошибок, оптимизация затронутого кода, тесты/lint/сборка и отчёт в agent.md/GitHub.
- Настройки добавлять вместе с каждой новой функцией. ИИ полностью отключаем: без скрытых запросов после выключения. Настройки не должны превращать главное меню в длинную простыню.
- Material 3, собственное оформление; скриншоты чужого приложения — функциональный ориентир, а не дефекты NoteLS и не образец для копирования пикселей.
- Оптимизация для слабого класса устройств, не отдельная ветка под Samsung A01. Нельзя обещать локальное распознавание на любом устройстве без проверки доступного движка/модели.
- Нет ненужного фонового опроса, декодирования оригиналов всех фото, вечных анимаций и I/O на UI-потоке. Форматирование/таблицы/аудио/приоритеты проверять в хранении, восстановлении и синхронизации; модель данных продумать до изменений.
- Не заявлять тестирование на физическом A01 или замеры батареи/памяти без запуска. Текущий cloud не имеет adb/emulator/Android SDK/JDK 17; CI обеспечивает сборку, тесты и моделирование Compose, а не физический телефон.
- Сохранять архитектурные границы для последующего KMP/iOS. Постоянный ключ не менять и не передавать в облако. Подписанный выпуск пока 1.10.1; CI debug не выдавать как обновление.

## Уточнения перед зависимыми этапами

1. Распознавание: голос → текст или также OCR фотографий? Пока не добавлять OCR от себя.
2. Голосовое: подтвердить отдельное аудиовложение; оно отличается от диктовки.
3. Автосинхронизация: нужна ли при закрытом UI на обоих устройствах? Это отдельный режим с расходом батареи и ограничениями Android.
4. Не обещать отсутствие правовых рисков ИИ без изучения условий выбранного провайдера; выбор/стоимость/передачу данных определить до подключения.
