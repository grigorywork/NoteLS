## Порядок работы

- Пользователь разрешил последовательную работу без вопросов между этапами: этап → аудит → исправления → оптимизация → тесты/lint/сборка. Новое указание в Codex от 12 ноября: реализовать этап51 и продолжать согласованную очередь, сохраняя каждый проверенный этап в GitHub; прежнее ограничение на завершение передачи50 относится к предыдущему чату.
- Настройки добавлять вместе с каждой новой функцией. ИИ полностью отключаем: без скрытых запросов после выключения. Настройки не должны превращать главное меню в длинную простыню.
- Material 3, собственное оформление; скриншоты чужого приложения — функциональный ориентир, а не дефекты NoteLS и не образец для копирования пикселей.
- Оптимизация для слабого класса устройств, не отдельная ветка под Samsung A01. Нельзя обещать локальное распознавание на любом устройстве без проверки доступного движка/модели.
- Нет ненужного фонового опроса, декодирования оригиналов всех фото, вечных анимаций и I/O на UI-потоке. Форматирование/таблицы/аудио/приоритеты проверять в хранении, восстановлении и синхронизации; модель данных продумать до изменений.
- Не заявлять тестирование на физическом A01 или замеры батареи/памяти без запуска. В среде заново установлены Android SDK35/Build Tools35.0.0/Gradle8.9; локально и в CI используется JDK17. Есть моделирование Compose/Robolectric; физического устройства/эмулятора и замеров ресурсов нет.
- Сохранять архитектурные границы для последующего KMP/iOS. Постоянный ключ не менять и не передавать в облако. Подписанный выпуск пока 1.10.1; CI debug не выдавать как обновление.
