Источник требований: текущий облачный чат и присланные пользователем скриншоты. Основной проект — приватный `grigorywork/NoteLS`, `main`. Исходная точка плана: `2fb36d25b96f78d946c7fb16901aa3588ec425bd` (1.10.2 / code 25).

## Правила выполнения

- Один запуск — один этап с аудитом, оптимизацией затронутого кода и исправлением найденных ошибок. Следующий этап не отмечать завершённым по одному плану.
- После кодовых изменений повышать версию, выполнять подходящие тесты, lint и сборку в GitHub Actions. Аудит и ограничения фиксировать в `agent.md`.
- На каждом этапе уменьшать ненужную работу UI, I/O и памяти: обновления только по необходимости и жизненному циклу, без добавления фонового опроса и служб. Не оптимизировать ценой потери сохранения, резервных копий, синхронизации, доступности или точности таймеров.
- Использовать Material 3, имеющиеся шрифты и локальные ресурсы. Не создавать дополнительные анимации, сетевые зависимости или сторонние библиотеки без необходимости.
- Подписанный устанавливаемый выпуск остаётся 1.10.1, пока нет безопасного согласованного способа подписи существующим ключом. CI debug не выдавать как обновление; ключ в чат не запрашивать и не менять.
- UI и расход ресурсов на Android проверять только при доступном изолированном устройстве/эмуляторе с тестовыми данными. Анализ исходников и Robolectric не называть замерами батареи/памяти.

## Проверка после каждого этапа

1. Проверить поведение, ошибки и сохранение состояния на затронутых путях, добавить регрессионные тесты там, где они проверяют реальный риск.
2. Проверить ненужные циклы, анимации, подписки, повторные чтения/записи и освобождение ресурсов; устранить найденное в пределах этапа.
3. Выполнить `:app:testDebugUnitTest :app:lintDebug :app:assembleDebug`, прочитать результаты.
4. Обновить статус этапа и `agent.md`, зафиксировать в GitHub без переписывания истории. На этом завершить запуск.
