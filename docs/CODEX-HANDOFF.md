## Подпись

Keystore/keystore.properties находятся только на компьютере пользователя. Не просить ключ в чате, не создавать новый постоянный ключ, не заменять подпись и не коммитить секреты. Существующий правильно подписанный выпуск: https://github.com/grigorywork/NoteLS/releases/tag/v1.10.1 . Облачный debug APK не предлагать как обновление. Подписать новый выпуск можно только прежним ключом в разрешённой пользователем среде.

## Надёжность передачи

Cloud-среда дважды возвращалась к старому снимку и теряла локальные изменения/коммиты/SDK. Поэтому перед продолжением обязательно проверить реальное содержимое GitHub и рабочей копии; исторические номера тестов не заменяют проверку текущих файлов. Эта передача опирается на опубликованный main и новый итог CI, а не на недоступные старые локальные коммиты.
