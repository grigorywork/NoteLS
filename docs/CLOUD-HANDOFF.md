## Дальнейшее продолжение

Продолжать согласованный план этапов 42–48: один запуск — один этап с аудитом и оптимизацией. Этап 42 завершён ранее; в текущем запуске завершается этап 43. Этапы 44–48 пока не реализованы. Следующая проверка UI и измерений требует изолированного Android-устройства/эмулятора. Для нового устанавливаемого обновления 1.10.4 нужен согласованный способ подписи существующим ключом; CI debug не выдавать как обновление.

1. Получить свежий main из GitHub и проверить релиз/CI, не восстанавливать проект из старых архивов.
2. Подготовить среду JDK 17 + Android SDK 35 / Build Tools 35.0.0. Gradle wrapper 8.9 уже включён. Команда проверки: ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --console=plain --max-workers=2 --no-daemon.
3. Проверить сценарии UI шрифтов, цитат и резервного копирования в изолированном эмуляторе на тестовых данных, включая повреждённый архив. Не трогать данные телефона пользователя. При доступном эмуляторе проверить остановку фоновой активности и собрать сведения о памяти/batterystats; не выдавать кодовую проверку за реальные измерения.
4. Передать пользователю APK из выпуска и короткую проверку на его телефоне: выбрать шрифт, сохранить цитату, создать копию, восстановить тестовые записи и фото. Самостоятельно данные пользователя не удалять.
5. Исправлять подтверждённые дефекты этого этапа и выполнять аудит. Новые функции без конкретного запроса не добавлять. Изменения фиксировать в GitHub.

## Подпись и секреты

Постоянный keystore и keystore.properties есть только в локальной рабочей копии на компьютере пользователя, исключены из Git. В облако и репозиторий не передавались. Не создавать новый постоянный ключ и не заменять подпись. Обычная debug-сборка в облаке/CI без ключа не устанавливается поверх пользовательской версии; такие APK не публиковать как обновление. Готовый v1.10.1 уже подписан правильным ключом. Для новых устанавливаемых обновлений потребуется доступный согласованный способ подписи, ключ в чат не запрашивать.
