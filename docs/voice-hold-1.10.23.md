## Поведение

По умолчанию удержание микрофона начинает распознавание, отпускание вызывает stopListening и ожидает итоговый текст. «Настройки → Голосовой ввод → Управление микрофоном» переключает удержание/два нажатия. Доступный click для TalkBack/клавиатуры позволяет запускать/завершать без удержания. При ожидании результата доступна отмена. Состояния запуска/прослушивания/распознавания отличаются, частичный текст не вставляется как окончательный. Системный сервис может сам завершить речь по тишине; автоматического перезапуска нет.

Выход/удаление отменяют микрофон ещё до ожидания записи БД; пока редактор загружается/закрывается, новый запуск недоступен. Уход редактора в pause, закрытие экрана или отмена жеста отменяют и уничтожают сеанс. Старые callback/таймеры не вставляют текст в заметку и не затрагивают следующий сеанс. Запрос разрешения не считается началом записи: после ответа нужно новое действие. Выбранный способ структуризации запоминается при запуске; язык UI не меняет язык распознавания (используется системный BCP47 tag). Результат вставляется через прежний редактор/историю/автосохранение.

Локальный режим использует только createOnDeviceSpeechRecognizer при Android12+ и фактической доступности. EXTRA_PREFER_OFFLINE не используется как обещание офлайн для обычного распознавателя. Отсутствие движка/языковой модели даёт сообщение с клавиатурой или явным выбором онлайн. Онлайн использует установленный системный сервис, который может передавать звук своему провайдеру; это обозначено в настройках. Модели не скачиваются приложением, нет скрытой смены режима. На старых/слабых устройствах доступны клавиатура и системный онлайн-сервис, удержание необязательно. Доступность и качество реального движка не заявляются без проверки устройства.

Убрана вводящая в заблуждение плашка AI на микрофоне: существующая структуризация — локальные правила, отдельный ИИ позже63. Не меняются пользовательские данные/правила содержимого; новые подписи переведены RU/EN.

## Аудит и оптимизация

Платформенная фабрика распознавателя отделена от VoiceSession/проверок автомата. Один активный recognizer; повторный запуск занятого не создаёт второй. Отпускание и cancel разделены: destroy только после результата/ошибки/отмены/таймаута. Сначала инвалидируется идентичность, затем cancel/destroy, поэтому синхронные/поздние ответы платформы игнорируются. Ошибки создания/start/finish и ошибки cleanup не удерживают сеанс.

10с на запуск, до90с прослушивания после ready (затем finish),15с на результат. Одноразовый Handler deadline на главный поток, не опрос/служба/авторестарт. Частичный текст до4000, итог до32000 UTF16 без разрыва surrogate pair. Буферы звука не копируются/сохраняются приложением. Regex структуризации компилируются лениво один раз вместо повторов для каждого предложения. Manifest queries для RecognitionService исправляет видимость системного движка на Android11+, новых разрешений/зависимостей/схемы нет. Постоянная подпись не менялась.
