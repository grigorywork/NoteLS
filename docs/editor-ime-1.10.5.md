# Этап 44 — панель редактора над клавиатурой

Дата: 2026-11-11. Исходная точка main: `4390add7ec18671e137f69ac545d6ec203e43742`.
Версия исходников: **1.10.5 / versionCode 28**.

## Подтверждённая причина и изменение

Раньше `imePadding()` находился на Column содержимого Scaffold. Нижняя NavigationBar была соседним `bottomBar` и этим отступом не охватывалась. Поэтому поле могло менять размер, пока клавиатура закрывала кнопки «Текст / Фото / Сигнал / Блокнот / Теги».

Стандартный Material 3 Scaffold выделен в `EditorScaffold`. IME-insets применяются вокруг всего Scaffold и потребляются на этом уровне. Внутренний padding Scaffold применяется к содержимому и потребляется один раз. Второй imePadding в Column убран. При открытии или изменении высоты клавиатуры переразмечается весь редактор, включая нижнюю панель и Snackbar.

Отступы системной навигации оставлены стандартным Material-компонентам. Не задаётся высота клавиатуры в dp и не добавляются обработчики размеров окна, опрос, фоновые задачи или новые пользовательские настройки для самого исправления. Корректная раскладка всегда включена.

## Аудит и нагрузка

- Изменения не затрагивают ввод, формат хранения, автосохранение, бэкап, синхронизацию и таймеры.
- Убрана дублирующая обработка IME в content. Реакция происходит через стандартные insets Compose, без дополнительных рекомпозиций по таймеру.
- Вынесенный контейнер использует Compose/Material 3 и не добавляет Android-only API в общую логику.
- Тестовые зависимости Compose UI test и test manifest ограничены test/debug; новых release-зависимостей нет.
