# Qwen в NoteLS

Инструкция для1.10.43/code66 и новее. На момент написания кандидат проходит полный CI; последний проверенный установочный выпуск —42. Актуальный результат — в [NEXT-CHAT.md](NEXT-CHAT.md).

1. Откройте **Настройки → Преобразователь текста** и включите преобразователь.
2. В строке **Провайдер** выберите **Qwen · Groq**. Модель уже задана, вводить её имя не нужно. OpenAI остаётся отдельным вариантом.
3. Раскройте **Лимиты и аккаунт Groq → Получить ключ Groq**. Это откроет [официальную страницу ключей](https://console.groq.com/keys). Для бесплатного использования оставьте аккаунт Groq на тарифе **Free**.
4. Вставьте свой ключ в поле **Новый API-ключ Groq** и нажмите **Сохранить ключ**. Ключ вводится в приложении; отправлять его в чат не нужно.
5. В редакторе выделите нужный фрагмент. Если выделения нет, преобразуется весь текст заметки. Откройте нижнюю кнопку **+ → Преобразовать текст**.
6. Проверьте текст в окне отправки, выберите связный текст или список и нажмите **Отправить в Groq**. До этого нажатия текст не отправляется.
7. Проверьте и при необходимости отредактируйте результат. Только **Заменить текст** применит его к заметке. Закрытие/отмена оставляют оригинал.

Free работает в пределах лимитов Groq. Приложение не может проверить тариф по API-ключу: на платном Developer-аккаунте запросы могут тарифицироваться. При исчерпании квоты NoteLS покажет ошибку, без автоматической смены модели, сервиса или тарифа. [Текущие лимиты](https://console.groq.com/docs/rate-limits), [условия тарифов](https://console.groq.com/docs/billing-faqs).

В Groq отправляется только текст из окна отправки, без заголовка заметки, вложений или истории. Хранение на стороне Groq регулируется [его условиями данных](https://console.groq.com/docs/your-data). Ключи Groq и OpenAI хранятся отдельно, зашифрованы на устройстве и не включаются в резервные копии. После переноса на другое устройство ключ нужно ввести там самостоятельно. Удаление ключа Groq не удаляет ключ OpenAI.

В английском интерфейсе: **Settings → Text transformer → Provider → Qwen · Groq → Groq account and limits → Get a Groq key**. В редакторе: **+ → Transform text → Send to Groq → Replace text**.

Реальная генерация с пользовательским аккаунтом в ходе разработки не выполнялась; автоматические проверки используют оффлайн HTTP-заглушки и облачный UI.
