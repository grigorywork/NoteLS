# NoteLS 1.10.1 — шрифты, цитаты и локальные резервные копии

Версия 1.10.1 / versionCode 24. Основной репозиторий: grigorywork/NoteLS, main.

## Изменения

- Резервная копия создаётся из согласованного снимка SQLite + WAL, без вызова checkpoint через execSQL на рабочей базе.
- Восстановление: ограниченная распаковка, проверка манифеста и формата, CRC, SQLite quick_check, версии, схемы Room, связей и числа записей. Текущие данные заменяются в одной транзакции. При ошибке вставки выполняется откат.
- Фото сначала готовятся в отдельном каталоге, пути переписываются под текущую установку. Старые фото удаляются после успешного коммита. Сохраняются заметки, задачи, блокноты, теги, защищённые записи и фотографии; настройки интерфейса в формат 1 не входят.
- После восстановления обновляются виджеты и заново ставятся будущие напоминания и таймеры. Перезапуск процесса не требуется.
- В настройках доступен список локальных копий: восстановление или сохранение в выбранную папку. Автоматические копии находятся во внутреннем хранилище приложения; предыдущие копии 1.10.0 из внешнего каталога также видны. Хранятся 5 последних архивов.
- Архивы пишутся во временный файл и становятся доступными только после завершения. Ручной экспорт не переносит срок следующей автоматической копии.
- Новая функциональность не добавляет постоянно работающие службы, WorkManager, будильники для бэкапа, wake lock или опрос по таймеру. Проверка срока — при открытии/закрытии активности; режим после заметки объединяет правки до выхода из редактора. События виджета сами по себе не запускают бэкап.
- Закрытие неизменённой заметки не записывает её повторно. Шрифты загружаются для выбранного семейства, вместо одновременного предпросмотра десяти семейств. Проверены 20 TTF: во всех есть 66 русских букв, включая Ё/ё. Добавлены 10 оригинальных OFL-лицензий и их просмотр.
- У цитаты дня доступны копирование, отправка и сохранение. Сохраняется автор и название произведения; фильтр автора переживает пересоздание экрана. Обновление дня выполняется при возвращении на экран, без фонового таймера. Сохранённая цитата участвует в автоматическом бэкапе.

## Ограничения

- Локальные копии приложения удаляются вместе с ним; для хранения отдельно используется «Сохранить в папку».
- Работа по расписанию проверяется по событиям использования; закрытое приложение не будится ради бэкапа. Принудительная остановка ОС может прервать незавершённую автоматическую копию; предыдущие завершённые архивы сохраняются.
- Измерение расхода батареи и памяти на физическом устройстве требует отдельного запуска. Android может оставлять процесс в собственном кэше; приложение не принуждает ОС постоянно держать его работающим.
