# Идущая задача в шторке

Подготовлено для1.10.64; до полного CI/подписи/независимой проверки не является подтверждённым выпуском.

В настройках редактора включите «Идущая задача в шторке». Если Android запрещает уведомления, нажмите «Разрешить» или «Настройки уведомлений». Затем запустите секундомер или таймер в задаче. У задачи с двумя работающими счётчиками будут два тихих уведомления. Одновременно показывается до20 задач.

Android обновляет счётчик самостоятельно, поэтому приложение не держит постоянный фоновый сервис и не опрашивает время каждуюсекунду. Формат живого счётчика устанавливает система; переключатель часов/дней меняет представление внутри NoteLS. Для неправдоподобно больших интервалов используется статическое «Время при обновлении».

«Пауза» останавливает только выбранный счётчик. «Выполнить» завершает задачу, останавливает оба и сохраняет её блокнот/текст/таблицы/вложения/даты. Настройка раздела выполненных продолжает работать как раньше. Нажатие на обычное уведомление открывает актуальную запись. У защищённой записи заголовок скрыт, изменение доступно через приложение после входа.

Выключение настройки убирает уведомления, сохраняя таймеры и данные. Force stop, перезагрузка, ограничения производителя или запрет канала могут скрыть уведомление; при следующем входе приложение восстанавливает его из сохранённых данных. Это не обещание нулевого расхода батареи и не результат физических измерений.
