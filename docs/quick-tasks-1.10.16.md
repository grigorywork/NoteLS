# Этап54а — быстрые задачи, 1.10.16 / code39, Room14

Добавлен по последнему запросу пользователя после53. «+» календаря открывает быстрый ввод на выбранный день; полный редактор заметки доступен отдельной кнопкой сверху. В месячном виджете добавлен «+». Он использует последний выбранный день этого виджета, а после смены месяца — сегодня для текущего месяца или первое число другого месяца. Дата также выбирается в быстром окне. Каждый виджет имеет отдельный PendingIntent с собственным URI.

Задача сохраняется автоматически через500мс после ввода и принудительно при выходе/уходе с экрана; отдельной кнопки «Сохранить» нет. «+» дожидается записи текущей, очищает ввод и начинает следующую. «+»/закрытие закреплены в шапке, содержимое прокручивается при клавиатуре/на узком экране. Пустые задачи не создаются, очищенная сохранённая задача получает tombstone для обмена. Ошибка записи оставляет текст и кнопку повтора, переход к новой задаче/закрытие не выполняется.

Время напоминания выбирается для указанной даты в локальном часовом поясе. В настройках можно отключить автоматическое открытие выбора времени; ручной выбор остаётся. «Без напоминания» убирает время. Прошедшее время, отказ уведомлений и ошибка AlarmManager показываются явно; текст задачи сохраняется, а неудачный сигнал не отмечается установленным. Это обычный reminderAt, отдельный срок задачи остаётся этапом62.

Stable syncId в SavedStateHandle, общий Mutex записи и Room-транзакция защищают от дублей при повторных нажатиях/пересоздании. Неотменяемое завершение записи сохраняет ID вместе с результатом. Для изменения существующей задачи применяется UPDATE, сохраняющий внешние ключи вложений и остальные свойства. Удалённая/защищённая запись не перезаписывается запоздалым черновиком. Сбой постановки очищает только соответствующие метаданные напоминания, не всю заметку; прежний сигнал отменяется. Завершённая задача не получает новый сигнал при правке текста. Платформенные напоминания выделены интерфейсом.

Текст ограничен32000 UTF16-символов для небольшого SavedState; превышение отклоняет новое значение, сохраняя прежний текст. Лента дня остаётся ленивой. Фонового опроса, служб и новых разрешений/зависимостей нет. Бэкап/синхронизация используют прежнюю модель NoteEntity без новой миграции.
