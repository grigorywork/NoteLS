# Создание записей в блокноте — кандидат1.10.62

Это описание изменения этапа88, пока не подтверждённый установочный выпуск.

Откройте меню и выберите блокнот. Нижняя кнопка «+» создаёт заметку в выбранном блокноте, а кнопка задачи — задачу в нём же. После сохранения, повторного открытия и выполнения задачи принадлежность сохраняется. В общих разделах новые записи также могут отображаться: это представление тех же записей.

Настройка автоматического скрытия выполненных из рабочих списков сохраняет прежнее действие. При её включении выполненная задача показывается в разделе выполненных, но её блокнот, текст, даты и идентичность не меняются. По умолчанию прежнее поведение сохранено.

Старые общие записи автоматически не распределяются: приложение не угадывает их исходный блокнот. Для них остаётся существующий явный выбор блокнота в редакторе.

Закрытый блокнот сначала нужно разблокировать. Создание не подменяется общей заметкой, если выбранный родитель исчез, был удалён или больше недоступен. Дневник использует свой существующий отдельный путь создания. Ошибка записи при явной смене блокнота сообщает о неудаче и сохраняет выбранное назначение для повторной попытки.
