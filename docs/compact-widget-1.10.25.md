# Компактный виджет — этап60,1.10.25/code48

Три строки последних публичных записей, закреплённые сверху; цвет заметок/задач, отметка выполнения и закрепления. Нажатие открывает конкретную запись, «+» — существующий общий экран быстрой задачи с автосохранением и выбором времени. День вычисляется при нажатии, включая переход через полночь. Отдельный виджет в системном списке, меню общих настроек, RU/EN подписи без перевода пользовательских данных.

## Аудит и оптимизация

Room16 заменяет только индекс видимых записей: покрывает порядок и метаданные защиты. SQL сначала выбирает максимум3 ID из индекса, затем читает только их короткие заголовки/текст (256 Unicode-кодпоинтов); без фото, оформления, таблиц и вложений. Защищённые записи и блокноты исключены даже при открытой сессии доступа, корзина/purged исключены. Переход повторно сверяет ID/syncId и текущую защиту. Старые строки полностью очищаются вместе с click PendingIntent; ошибка обновления явно скрывает содержимое.

Один наблюдатель Room только при наличии установленного компактного виджета; без периодических alarm/worker/service, updatePeriodMillis=0. distinctUntilChanged, кеш одинаковых RemoteViews, trailing250ms для правок текста без потери последней правки. Изменение состава/языка/настроек и явное обновление немедленные. Удаление последнего виджета отменяет scope; повторная установка получает свежий снимок. Настройки альфа ограничены конечным0..1. Четыре новых замечания lint устранены: ресурсы символов/симметрия отступов и явно Application в долгоживущем owner; остаются15 прежних warnings и2 информации. Минимум180×208dp, три строки и кнопки минимум48dp, одна строка с ellipsis, без декодирования фото/анимаций/тиков.

Обнаружен и исправлен унаследованный с56 сбой запуска MainActivity: локализованный ContextWrapper нельзя напрямую приводить к ComponentActivity. NavGraph извлекает Activity из цепочки контекстов; переходы выполняются в Android UI thread. Начальный widget intent обрабатывается лишь без savedInstanceState; повторный intent получает новый sequence и не теряется при завершении старого. Существующие анимации главной сохранены.
