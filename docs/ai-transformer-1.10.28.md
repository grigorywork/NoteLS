## Аудит и ресурсы

Вход до16000 UTF-16 единиц, результат до32000, ответ HTTP до64КиБ, request JSON до128КиБ. Предварительные лимиты не создают пустой черновик; границы выделения нормализуются по surrogate pair. HTTP выполняется в IO, локальная обработка в Default, regex подготовлен один раз. Connect10s/read30s/общий запрос45s, redirects отключены, штатная проверка TLS без trust-all. Ошибки представлены кодами, без raw HTTP/ключей/текста в сообщениях журнала. Извлекаются только completed assistant output_text, reasoning и прочие элементы не становятся результатом; malformed/incomplete/refusal/overflow отклоняются.

Один запрос на открытый предпросмотр, generation guard, отмена на закрытии/STOP/выключении, закрытие соединения и игнорирование позднего результата. Уже отправленный запрос может обрабатываться сервисом после локальной отмены; отмена не является обещанием отсутствия тарификации. Во время диктовки/импорта/записи запуск инструмента отключён. Доступ/ID/syncId/ревизия заметки и блокнота проверяются перед отправкой/применением; изменение текста/форматирования/доступа отвергает устаревший результат. Новая scalar TransformAccess не меняет прежний media observer и не загружает content/вложения. Room17/протокол2 без миграции и новых runtime-зависимостей/разрешений/worker/service.
