# Этап56 — русский и английский интерфейс

1.10.21/code44, Room15, протокол2. Следующий этап57 — общая аналитика и фильтр по блокнотам.

## Поведение

«Настройки → Язык интерфейса»: Русский / English. По умолчанию сохраняется прежний русский интерфейс; выбор хранится на устройстве и применяется без перезапуска Activity. Переведены главная/корзина/блокноты, редактор и форматирование, таблицы/фото/камера, календарь/таймер, биометрия, настройки/бэкапы, синхронизация, аналитика, голосовые ошибки, быстрые задачи и виджет. Английские подписи доступны офлайн.

Меняются подписи/описания доступности/ошибки и формат отображения дат/размеров. Названия и содержимое заметок/задач/блокнотов/тегов, пользовательская цитата, тексты/авторы QuotesData, правила и содержимое голосовой структуризации, таблицы и оформление не переводятся. Имя записи, совпадающее с русской подписью кнопки, остаётся пользовательским именем. Идентификаторы/enum names/JSON/QR/ключи цветов/даты хранения и схема не меняются. Подсказки для отсутствующего названия/блокнота формируются в UI, а не записываются в данные аналитики. Автоматически созданный заголовок новой конфликтной копии использует язык интерфейса, прежние записи не переименовываются.

Переключение сохраняет черновик, историю отмены, позицию и существующие анимации; нет key/recreate вокруг редактора. Для Material date/time picker используются scoped Context/Configuration, сохраняющие базовую Activity (включая BiometricPrompt). Locale.getDefault не меняется: язык распознавания речи/содержимое не переключаются от выбора UI. Системные окна Android управляются самим Android.

Виджет получает выбранный язык независимо от языка launcher: месяц, дни недели и описания кнопок; выбранный день/URI/режимы выполнения сохраняются. Канал напоминаний получает локализованное имя без сброса пользовательских разрешений. Оба языка включены в APK/App Bundle, language split отключён; языковые ресурсы ограничены RU/EN без подключения Play Core.

## Аудит и оптимизация

541 запись общего каталога: русские ключи и ленивый английский map, без сети/внешнего перевода. Пока используется русский, английский map не создаётся. Подстановка аргументов выполняется за один проход: проценты, emoji, фигурные скобки и похожие на placeholders фрагменты пользовательского текста остаются буквальными. Контекст отличает Redo истории от Retry повторной попытки. Статические enum/цвета/шаблоны хранят неизменяемые данные, отображаемая подпись вычисляется для текущего языка.

Изменения выполнены по Kotlin PSI текущего компилятора; отдельный повторный аудит не нашёл неучтённых русских UI-литералов. Исключены данные цитат/голосового преобразователя, неизменяемые UI-ключи enum/палитр и локализуемые ресурсы. Эти вспомогательные инструменты работают только в облаке и не являются зависимостями приложения. Новых runtime-зависимостей/служб/опроса нет. Превью/лимиты памяти/IO, защита/биометрические ключи и остановка невидимых анимаций сохранены.
