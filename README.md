# NoteLS

Android-приложение заметок автора **MSS9LN**. Заметки, задачи, виджеты, напоминания, цитаты, шрифты и резервное копирование. Прямая синхронизация устройств по Wi-Fi с сопряжением через QR-код.

Актуальная версия: **1.10.0**, `versionCode 23`, этап 39.

## Сборка

Нужны JDK 17 и Android SDK Platform 35 / Build Tools 35.0.0. Gradle 8.9 загружает wrapper.

Windows:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Linux/macOS:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Укажите путь Android SDK в локальном `local.properties` (`sdk.dir=...`) или через `ANDROID_HOME`.

Для сборки, которая обновляет установленные версии с 1.8.1 без переустановки, нужны существующие локальные `notessync-release.keystore` и `keystore.properties`. Они исключены из Git. Архивы исходников содержат ключ: не загружать их в репозиторий или выпуски. Без ключа debug использует стандартную подпись Android и не заменяет установленную сборку проекта.

## Статус

Код приложения перенесён без изменений. Предыдущие сборки и проверки описаны в `agent.md`; при переносе новая сборка не выполнялась. Проверка создания и восстановления бэкапа 1.10.0 на физическом устройстве остаётся за пользователем. Планы: стабилизация Android, затем Kotlin Multiplatform / Compose Multiplatform для других платформ; перед коммерческим релизом нужен экран лицензий.
