# NoteLS

Android-приложение заметок автора **MSS9LN**. Заметки, задачи, виджеты, напоминания, цитаты, шрифты и резервное копирование. Прямая синхронизация устройств по Wi-Fi с сопряжением через QR-код.

Актуальные исходники: **1.10.26**, `versionCode 49`, этап61. Подписанный выпуск для установки: **1.10.1**.

Основной репозиторий: https://github.com/grigorywork/NoteLS (приватный). Все последующие изменения ведутся здесь; локальная папка — рабочая копия этого репозитория.

## Сборка

Нужны JDK 17 и Android SDK Platform 35 / Build Tools 35.0.0. Gradle 8.9 загружает wrapper.

Windows:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Linux/macOS:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Укажите путь Android SDK в локальном `local.properties` (`sdk.dir=...`) или через `ANDROID_HOME`.

Для сборки, которая обновляет установленные версии с 1.8.1 без переустановки, нужны существующие локальные `notessync-release.keystore` и `keystore.properties`. Они исключены из Git. Архивы исходников содержат ключ: не загружать их в репозиторий или выпуски. Без ключа debug использует стандартную подпись Android и не заменяет установленную сборку проекта.

Проверена фоновая активность: исправлены обновления UI-таймеров в фоне, отмена TCP-соединений, остановка голосового ввода и освобождение ресурсов QR-сканера. Результаты и ограничения — [аудит этапа 41](docs/background-activity-1.10.2.md). Сборка 1.10.2 в CI проверочная; нового выпуска с постоянной подписью нет.

Шрифты, цитаты и локальный бэкап доработаны в 1.10.1. Подробности, ограничения и проверки — в [аудите этапа 40](docs/backup-and-fonts-1.10.1.md). Фоновый таймер или постоянно работающая служба для резервного копирования не используются. Проверка на физическом устройстве и измерения батареи остаются отдельной проверкой.
