## 1. Что это за продукт

**NoteLS** — Android-приложение заметок (начиналось как клон Evernote, далее пошёл свой путь).
Ключевая фишка — **синхронизация между устройствами без облака**: QR-код → рукопожатие → прямая передача по Wi-Fi (TCP + AES-256/GCM).

- Пакет: `com.notessync.app`
- Стек: Kotlin, Jetpack Compose, Material 3 (динамическая тема), Room, Navigation-Compose, KSP
- minSdk 26, targetSdk/compileSdk 35, buildToolsVersion 35.0.0, Gradle 8.9 + AGP, Java 17
- Авторская подпись на иконке/в приложении: **MSS9LN**

## 4. Что обсуждали (контекст и договорённости)

### Мультиплатформа и коммерция (важно для архитектуры!)
- Пользователь планирует порты на **iPhone, Windows, Linux** и возможную **продажу** приложения.
- Согласованный путь: **Kotlin Multiplatform + Compose Multiplatform** (UI и логика уже на Kotlin/Compose — перенос, а не переписывание). Сначала добить Android до стабильного состояния, потом портировать.
- Платформенно-зависимые куски (при порте нужны адаптеры): SpeechRecognizer, BiometricPrompt, виджеты календаря (на iOS — WidgetKit/Swift), быстрая заметка, уведомления/будильники, Room (есть мультиплатформенная версия).
- **Правило для новых этапов:** не углублять зависимость логики от Android-only API без необходимости, изолировать платформенный код за интерфейсами/менеджерами.
- Лицензии совместимы с продажей: Kotlin/Compose/Material 3 — Apache 2.0; шрифты — OFL (коммерция ОК). Обязательство: добавить экран «лицензии открытого ПО» в настройки — отдельный этап до релиза.
- Издержки: Apple Developer $99/год + Mac/Xcode для iOS; для Windows желателен платный сертификат подписи (иначе SmartScreen); на Linux продажа через свой сайт.
- Правовой статус: клонирование механик Evernote легально (идеи не охраняются), своё название/иконка/код — чисто.

### UI-конвенции
- Интерфейс — только стандартные компоненты Material Design 3, динамическая тема, без самодельных кнопок.
- Тексты лаконичные, строки не мелкие, выравнивание по сетке.
- Требования пользователя к аккуратности: «чтобы органично было для системы», «чтобы сильно не бросались в глаза» — новые элементы внедрять в существующие паттерны, не плодить визуальный шум.

### Лицензии контента
- Античные цитаты — общественное достояние. Пелевин/Кастанеда — короткое цитирование с атрибуцией (ст. 1274 ГК РФ).
- Шрифты — SIL OFL (google/fonts), коммерческое использование разрешено, нельзя продавать шрифты сами по себе.

## 6. Как собирать проект

### Обычная среда (Android Studio / локальная машина)
Стандартно: JDK 17, Android SDK 35, `./gradlew :app:assembleDebug`. Debug-сборка подписывается release-ключом из `keystore.properties` — APK ставится поверх предыдущих.

### Песочница Kimi (проверенный рецепт, 51 с)
Рабочее дерево: `/mnt/agents/.build-home/proj`. После перезапуска песочницы: `apt-get install -y openjdk-17-jdk-headless` (нужен ПОЛНЫЙ JDK — jlink для JdkImageTransform). Затем:

```
GRADLE_USER_HOME=/root/.gradle-nls \
ANDROID_HOME=/mnt/agents/.build-home/android-sdk \
/mnt/agents/.build-home/gradle-dist/gradle-8.9/bin/gradle \
:app:assembleDebug --console=plain --max-workers=1 --no-build-cache --no-daemon
```

Подводные камни (уже встречались, не наступать):
- Кэш Gradle держать в `/root/.gradle-nls` (переживает перезапуски, 1.3 ГБ). На FUSE-диске `/mnt/agents` transforms-кэш портится (metadata.bin/EOFException), `/tmp` стирается.
- Память ~3.8 ГБ: `org.gradle.jvmargs=-Xmx1408m` + `--max-workers=1`, иначе OOM на dex/AAPT2.
- `--no-build-cache` — кэш тасок был отравлен (фантомные Unresolved reference).
- Офлайн не собирается (пары jar нет в кэше), нужен онлайн; maven.google.com быстрый, services.gradle.org медленный (Gradle качать с mirrors.cloud.tencent.com).
- Сбой D8 на FUSE лечится `rm -rf app/build/intermediates/project_dex_archive`.
- При записи Kotlin-файлов через Python экранировать `\\n` и `\$`.
- `pkill -f java` убивает собственную команду — убивать по PID через awk.
